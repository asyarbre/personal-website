## Introduction

Welcome to my personal website! This site serves as a portfolio to showcase my projects, skills, and experiences. Here, you will find detailed information about the technologies I use, the projects I've worked on, and my journey as a developer.

## Technologies I Use

I primarily work with the following technologies:

- **Next.js**: A powerful React framework for building server-side rendered applications.
- **TypeScript**: A typed superset of JavaScript that helps catch errors early and improve code quality.
- **TailwindCSS**: A utility-first CSS framework that allows for rapid UI development.
- **Shadcnui**: A component library that provides a set of customizable UI components.
